## 🚀 Installation

```bash
git clone https://github.com/i-wwww/vague.git
cd vague
pip install -r requirements.txt
```
Navigation:

1-4 - Select category

[H] - Help menu

[T] - Change themes

[C] - Credits

[Q] - Quit

## 📖 Usage
```bash
Launch: python main.py or just use start.bat

Select category using number keys [1-4]

Choose command number to execute

Press [B] to go back

Press [T] for themes

Press [H] for help

Press [Q] to quit

```
